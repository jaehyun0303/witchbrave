# 위치브레이브 (Witch Brave) — 로비 UI 디자인 스펙

3D 아레나 액션 게임용 UI 목업 7화면. 모든 화면은 `screens/*.html` 로 독립 실행되는 1280×720 고정 아트보드(정적 HTML/CSS/인라인 SVG, JS 없음).
브라우저에서 열어 눈으로 확인한 뒤, 사용하는 UI 프레임워크(예: React, Unity UI Toolkit, Godot 등)로 옮겨 구현하면 된다.

## 디자인 토큰 (소스에서 가장 많이 쓰인 값)
- 잉크(외곽선/본문): `#2b1830` — 두꺼운 외곽선(3~5px) + 하단 드롭 섀도우 스타일
- 크림: `#fff3df`, `#ffe4bd`
- 골드(주요 버튼/강조): `#ffb02e`, `#ffc233`, `#ffd45c`
- 핑크: `#ff5c8a`, `#ff8fb1` / 위험·알림: `#d81e45`
- 민트: `#3ddbb0` / 하늘: `#5cc8ff` / 보라(영웅 등급): `#b57cff`
- 보조 텍스트: `#4d3a55`, `#6b4a63`
- 폰트: Jua(UI), Black Han Sans(로고·큰 제목), Noto Sans KR(보조). 모두 Google Fonts.
- 컴포넌트 규칙: 라운드 큰 버튼, 굵은 외곽선, 아이콘은 인라인 SVG(이모지 없음). 대비는 밝은 버튼 위 어두운 글씨, 어두운 배경 위 흰 글씨.

## 중요한 자리표시자
- **캐릭터 일러스트/3D 모델은 모두 점선 실루엣 슬롯**이다(로비 중앙, 캐릭터 카드, 미리보기, 뽑기 무대, 로딩 화면의 A·B). 실제 캐릭터 아트로 교체할 위치.
  - 권장: 투명 배경 PNG(또는 3D 렌더), 로딩 화면 슬롯은 약 230×380 비율(실제 600×900 이상 권장).
- `[업데이트 이름]`, `[버전 번호]`, 64% 진행도, 수치·가격·문구는 모두 샘플. 업데이트마다 로딩 화면은 슬롯 그림·배경·업데이트 칩만 교체하는 구조.
- 로딩 화면 배경: 왼쪽 아래 흑청 아공간(눈 SVG), 오른쪽 위 하늘 빛. 대각선 경계 폴리곤은 `clip-path` 로 구현되어 있음.

## 구현 시 참고
- 3D 로비 바닥은 CSS `perspective` 체커 바닥으로 흉내낸 것. 실제 게임에서는 3D 씬이 대체한다.
- 해상도 대응: 기준 1280×720. 앵커(좌/우/하단 고정)와 9-slice 버튼을 쓰면 다른 비율로 확장하기 쉽다.
- 버튼은 모두 `<button>`, 아이콘 전용 버튼에는 `aria-label` 이 있다.
- 상태 정의가 필요한 컴포넌트: 미션 행(받기/진행/완료), 캐릭터 카드(보유/선택/잠금), 모드 카드(일반/선택/잠금/이벤트), 상품 카드(기본/추천).
